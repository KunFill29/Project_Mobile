# Project Mobile

A modern Android application built with Jetpack Compose.

## Features
- **Modern UI:** Developed with Jetpack Compose and Material 3.
- **Navigation:** Seamless screen transitions using the Navigation component.
- **Firebase Integration:** Authentication and Firestore support.
- **Responsive Layouts:** Utilizes Material 3 Adaptive Navigation Suite.

## Tech Stack
- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose
- **Database/Auth:** Firebase
- **Architecture:** MVVM (Model-View-ViewModel)

## Getting Started
To run this project, ensure you have:
- Android Studio Ladybug or later.
- A Firebase project set up with `google-services.json` in the `app/` directory.
